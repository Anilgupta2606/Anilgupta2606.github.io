Channel Check — Privacy Policy

Last updated: 13 November 2026

Channel Check is a personal tool. It is used only by its owner, on the owner's own computer, to read the statistics of the owner's own YouTube channel and suggest how to improve future videos. It is not offered to anyone else.

What it accesses

With the owner's permission, through Google's sign-in, it reads (read-only):

  • YouTube Data API: the channel's name and its videos' titles, descriptions, lengths, upload times and public counts (views, likes, comments).
  • YouTube Analytics API: the channel's own reports — views, watch time, audience retention, traffic sources, impressions and click rate, likes, shares and subscribers gained.

It never uploads, edits or deletes anything, and never posts, comments or changes channel settings.

Where the data stays

  • Everything is stored only on the owner's own computer. There is no server and no database elsewhere.
  • The sign-in token is kept in a file only the owner's computer account can read, and is sent only to Google.
  • Channel statistics are not sold, shared or transferred to anyone, and are not used for advertising.
  • To write suggestions, the tool may send only public words of a video (its title, description and public captions) to an AI writing service; the private YouTube Analytics numbers are not sent.

Removing access

Access can be removed at any time: sign out inside the tool, which deletes the stored sign-in, or remove "Channel Check" at myaccount.google.com/permissions. The tool's stored data can be deleted from the owner's computer at any time.

Google API Services

Channel Check's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
